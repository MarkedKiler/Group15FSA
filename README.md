## Requirements

The group must complete the following requirements:

- Create one GitHub/GitLab repository for the group.
- Each member has their own branch.
- Each member must make at least one commit.
- Each member must practice merging their branch into the `main` branch.
- The group must practice creating and resolving merge conflicts.
- The repository can use any programming language or content, such as JavaScript, Java, .NET, etc.

## Git Operations Practiced

- Initialize a Git repository.
- Create and commit files.
- Create and switch branches.
- Rename `master` to `main`.
- Merge branches.
- Checkout an older version.
- Create and resolve local merge conflicts.
- Connect the local repository to GitHub/GitLab.
- Push changes to the remote repository.
- Pull changes from the remote repository.
- Create and resolve remote merge conflicts.
